# Тесты

Python-тесты находятся в `tests/python` и запускаются из `src/python-pipeline`.

Go-тесты расположены рядом с тестируемыми пакетами внутри `src/go-collector/internal/*`.
Это стандартная практика Go: пакеты `internal` нельзя импортировать из произвольной
директории вне родителя модуля, поэтому перенос всех Go-тестов в корневую `tests/`
сделал бы тесты хрупкими или потребовал бы раскрывать internal API.
